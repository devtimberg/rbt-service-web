# 0016. Серверная блокировка закрытых MVP-разделов

Дата: 2026-11-01
Статус: accepted

## Контекст

Кнопки закрытых разделов открывают окно «Этот раздел ещё в работе», но прямой ввод адреса позволял открыть каталог, корзину и другие незавершённые страницы. Блокировка должна охватывать также подразделы и не отдавать содержимое закрытой страницы до гидрации.

## Решение

Список `LOCKED_SECTIONS` и `isLockedSection` находятся в `shared/config/locked-sections.ts`. Фича `locked-section` сохраняет публичный API, переэкспортируя проверку из общего конфига. `next.config.ts` строит из того же списка временные редиректы 307 с каждого адреса и его подразделов (`/:path*`) на главную с параметром `section-locked=1`.

Корневая раскладка показывает существующее окно-заглушку при наличии параметра. При закрытии удаляет параметр через `router.replace`, сохраняя остальные параметры и hash. Основная страница и вызов мастера доступны; неизвестные адреса вне закрытых префиксов обрабатываются обычным 404.

## Последствия

- Для добавления или открытия раздела меняется один список; серверная блокировка и кнопки не расходятся.
- Содержимое закрытой страницы не выдаётся по прямому запросу. Это ограничение доступности MVP-разделов, не авторизация (ADR 0010).
- Изменение списка требует пересборки приложения, как и остальных правил `next.config.ts`.
