# 0014. Подтверждение ухода с заполненной формы

Дата: 2026-11-01
Статус: accepted

## Контекст

Форма вызова мастера должна предупреждать о потере данных до перехода по ссылкам, закрытия раздела и возврата по истории. При отмене перехода введённые значения и открытая страница сохраняются. При перезагрузке черновик восстанавливается из sessionStorage без предупреждения. В Next App Router нет публичного блокировщика маршрутов; приватный router и beforePopState использовать нельзя.

## Решение

Локальный React-контекст NavigationGuardProvider живёт над общей раскладкой. Форма регистрирует условие блокировки и действие удаления черновика, SmartLink передаёт клиентский переход через onNavigate, программное закрытие раздела — через request. Диалог остаётся на уровне app и использует существующий ConfirmDialog. Контекст хранит только ожидающее действие навигации, не данные формы; глобальный стор не вводится.

Для возврата по истории при регистрации заполненной формы добавляется служебная запись текущего адреса с сохранением состояния Next. Обработчик popstate в фазе capture удерживает текущий экран до решения пользователя; при подтверждении пропускает служебную пару, при отмене остаётся на форме. Опустевшая форма не блокирует переход, служебная запись пропускается. Приватные методы Next и подмена router не используются. Перезагрузка и закрытие вкладки не блокируются.

## Последствия

- Новые программные переходы с блокируемой страницы должны использовать request; обычные ссылки — SmartLink.
- Формат History API и взаимодействие с Next требуют браузерной проверки при обновлении Next. Служебные записи не должны размножаться при вводе, очистке и повторном заполнении.
- Отмена ухода сохраняет форму. Подтверждение удаляет черновик; поздний ответ мутации не меняет экран. Уход не гарантирует отмену обработки будущим сервером.
- API и данные черновика остаются в слайсе master-call. sessionStorage не обещает уничтожение данных при восстановлении браузером сессии вкладки.
