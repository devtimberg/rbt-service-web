# 0005. Свои UI-примитивы без shadcn, Radix и cva

Дата: 2026-10-15
Статус: accepted

## Контекст

UI был на shadcn/ui (New York), Radix и cva. Эталон rbt-web использует собственные примитивы; зависимостей на headless-библиотеки, ради нескольких компонентов, много.

## Решение

Все примитивы лежат в `src/shared/ui` и написаны на Tailwind с токенами из `tokens.css`. Модалки и шторки строятся на нативном `<dialog>`, Popover и Tooltip написаны самостоятельно. Варианты задаются явными картами классов и `cn()` (clsx + tailwind-merge), без `cva`.

Примитив не несёт собственных стилей сверх необходимого: семантика выбирается пропсом, а не отдельным компонентом на каждый тег (`Box`/`Stack`/`Text`/`List` с `as`, `Heading` с `level` и `size`, `Button variant="unstyled"`, голый `Input` рядом со стилизованным `TextInput`). Так один примитив покрывает несколько HTML-элементов, а оформление остаётся в классах места использования. Применение примитивов вместо голых элементов обеспечивает линт, см. [0008](0008-no-bare-html-elements.md).

## Последствия

- Меньше зависимостей и полный контроль над доступностью и анимацией.
- Новые случаи (модал, таб, кнопка) решаются расширением существующего примитива.
- Radix, shadcn и headless-библиотеки не добавляем.
- Поведение сложных примитивов (фокус, закрытие по Escape и клику вне) поддерживаем и тестируем сами.
