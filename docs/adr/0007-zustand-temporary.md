# 0007. Zustand как временное решение до API

Дата: 2026-10-15
Статус: accepted, частично заменён [0009](0009-nextjs-css-modules-rtk-query.md) (данные сервера в RTK Query с фазы 3)

## Контекст

API корзины, избранного и истории поиска пока нет, а интерфейс нужно показывать уже сейчас. Данные должны переживать перезагрузку.

## Решение

Корзина (`entities/cart`), избранное (`entities/favorite`) и история поиска (`features/search-products`) живут в zustand-сторах с сохранением в браузерное хранилище. Это временная мера, остальное состояние остаётся в TanStack Query, URL и `useState`.

## Последствия

- Новые глобальные сторы не заводим.
- Когда появится API, сторы заменяются на `queryOptions` и мутации в тех же сущностях, а zustand удаляется из зависимостей.
- Состояние хранится на клиенте, на SSR оно пустое, поэтому такие блоки не должны ломать гидратацию.
