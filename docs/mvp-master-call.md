# MVP, этап 3: вызов мастера

План последнего этапа MVP по макетам Figma. Этапы 1 (поля по «[C] Fluent Input») и 2 (закрытые разделы на главной) закрыты: коммиты `bdd37ca` и `fa980e5`. Правила проекта действуют как в [AGENTS.md](../AGENTS.md): `make check` после правок, `make ci` перед коммитом.

## Что решено

- Сценарий из двух экранов: **форма с чеком** → **«Заявка создана»**. Выбора времени, таймера подтверждения и экрана «Заявка подтверждена» с полем «Имя» в MVP нет.
- Поля формы: вид техники, телефон, комментарий до 255 символов. **Поля «Имя» нет и не будет**, строки «Заказчик» в чеке тоже.
- Дата и время в чеке — текущий момент, а не выбранный слот.
- API пока нет: мутация с заглушкой (`queryFn` с фейковым ответом и задержкой). Контракт подключим позже, не переделывая UI.
- «Заказать запчасть» ждёт макета: раздел закрыт в `src/features/locked-section/model.ts`, в этом этапе его не трогаем.

## План

### 1. Шрифт чека

Чек набран **JetBrains Mono** (Bold 18.4 — шапка и номер, Regular 16 — строки, 14.8 — дата и сноска, 12 — согласие, 10 — реквизиты). Пакета в проекте нет.

- `pnpm add @fontsource-variable/jetbrains-mono`, подключить через `next/font/local` в [fonts.ts](../src/app/styles/fonts.ts) по образцу Inter: подмножества latin и cyrillic, каждое своим семейством, без сети.
- Токен `--font-mono` в [tokens.css](../src/shared/ui/tokens.css) с перечислением семейств.

### 2. Примитив `Receipt` в `shared/ui`

Чек на двух экранах одинаковый, меняются только данные. Примитив без бизнес-текстов:

- `Receipt` — бумага: белый фон, радиус ~2.5px, отступы ~34/30, gap ~25, зубчатый верхний (на «Заявка создана» и нижний) край. Зубцы в `Blank` не нарисованы, посмотри родителя чека (`153:436` на десктопе) и сделай их через `mask`/`clip-path` в CSS, без картинки.
- `ReceiptRow` — строка «Услуга ........ Ремонт»: подпись слева, значение справа, точки-заполнитель между ними растягиваются (flex + `border-bottom: dotted` или `radial-gradient`). Пустое значение рисуется подчёркиванием `______`. Многострочный вариант для «Комментарий от заказчика».
- `ReceiptRule` — пунктирный разделитель (в макете `rule` под шапкой).
- Папка `shared/ui/receipt/`, строка в `shared/ui/index.ts`, пример на `/_dev/ui`.

### 3. Модель и API

- `entities/master-call` (новая сущность; если не хочется заводить сущность ради одной мутации, можно оставить в `pages/master-call`, но эндпоинт по правилам кладётся в `entities/<entity>/api.ts`):
  - `api.ts`: `api.injectEndpoints` → мутация `createMasterCall({ category, phone, comment })` → `{ number: string, createdAt: string }`. `queryFn` пока фейковый: задержка ~600 мс, номер вида `1589-2147` (4 цифры, дефис, 4 цифры). Ошибки `ApiError` превращать в сериализуемый объект, как сказано в AGENTS.md.
  - Файл без хуков, `useCreateMasterCallMutation` вызывать в клиентском компоненте.
- `pages/master-call/model/schema.ts`: zod-схема формы с текстами ошибок и unit-тест.
  - `category`: необязателен (вид техники можно не выбирать).
  - `phone`: пусто — «Обязательное поле», иначе не мобильный российский номер (`isValidPhone`) — «Некорректный номер телефона».
  - `comment`: необязателен, до 255 символов.

### 4. Экран формы (готово)

- `react-hook-form` + `zodResolver`, `<Form noValidate onSubmit={handleSubmit(onValid)}>`, режим по умолчанию.
- Десктоп: две колонки, слева заголовок «Вызвать мастера», хлебные крошки «🏠 — Вызвать мастера» и поля, справа чек. Внизу белая полоса с кнопкой «Создать заявку» справа.
- Мобильный: поля, под ними чек, кнопка «Создать заявку» закреплена внизу шторки.
- Чек живой: техника, телефон (`formatPhoneDisplay` по мере ввода, пусто → подчёркивание) и комментарий берутся из `watch()`. Номер `____-____` до отправки.
- Дата «от ДД.ММ.ГГГГ ЧЧ:ММ» — текущее время **на клиенте после гидратации** (на сервере другой часовой пояс, будет рассинхрон SSR). Обновлять раз в минуту, пока форма открыта. Можно взять `useSyncExternalStore` с серверным снимком `null` и показывать до гидратации `__.__.____ __:__`.
- Отправка: `isLoading` → `Button loading`. Ошибку сервера по полю класть в `setError(..., { type: 'server' })`, общую — в `FormAlert`.
